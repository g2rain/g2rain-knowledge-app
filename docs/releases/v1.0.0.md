# v1.0.0 · G2rain（谷雨）知识库运营应用

这是 G2rain（谷雨）开源智能体平台中负责知识库运营的 Vue 3 微前端应用首个稳定版，与 `g2rain-knowledge v1.0.0` 配套。它管理知识内容、版本、审核、处理、发布和检索/问答效果验证；不单独提供平台整体的身份、权限、网关、知识处理或模型能力。

## 本次交付

- 知识内容、版本、审核、处理、发布、分类/标签/回复模板和效果验证页面。
- Vue 3、TypeScript、Vite、qiankun 与 `@g2rain/*` 公共包；支持独立运行和主壳集成。
- Node.js `>=22`、npm 和锁文件 `package-lock.json`；`npm ci && npm run build` 是当前仓库完整自动构建范围。本仓没有独立测试脚本。
- 根目录 Dockerfile 使用 Node 22 Alpine 构建，并以 OpenResty Alpine 运行；入口 `/docker-entrypoint.sh`，声明端口 `8080`（生产应显式设置 `SERVER_PORT=8080`）。

## GHCR 镜像

镜像地址为 `ghcr.io/g2rain/g2rain-knowledge-app`。稳定 tag `v1.0.0` 触发后，工作流推送 `1.0.0` 和 `sha-<完整提交 SHA>`；不会推送或更新 `latest`。OCI 元数据包含源仓库、标题、描述、版本、提交和 `Apache-2.0` 许可证。

发布按 `feature/* 或 fix/* → develop → main` 进行。发布改动、工作流与本说明必须先进入 `main`，再在经验证的 main 提交创建 `v1.0.0`。工作流校验 tag 格式、main 血缘、该 tag 提交中的本说明以及 `package.json` 版本，随后运行 `npm ci`、`npm run build`、容器构建与 GHCR 推送。

## 镜像内容与安全

最终镜像包含 Vite `dist/`、Lua 签名实现、Nginx 模板与启动脚本，以及 `lua/keys/README.md`；不包含源码、Node 依赖、`.env`、`.env.production` 或 `lua/keys/` 中的真实密钥。构建上下文会读取已跟踪的 `.env.production`，目前只有公开路径与运行时 SSO 占位符；维护者不得在其中添加 Token、私钥、密码或私有地址。

生产 IAM/Lua 密钥必须以 Kubernetes Secret、Docker Secret 或受控 Volume 挂载到容器的 Lua keys 目录。`.dockerignore` 仅影响 Docker 构建上下文，不能清除 Git 中已跟踪的敏感信息；公开源码前仍须人工检查 Git 历史和跟踪文件。

## 验证状态与限制

- 已记录：维护者在 2026-10-19 确认服务器端验证通过；具体环境、平台依赖版本和日志未随记录提供。
- 本次发布准备的自动验证范围为 Actions 中的 `npm ci` 和 `npm run build`；Docker 构建、GHCR 推送、匿名拉取及实际部署是否成功，以对应 Actions 与目标环境记录为准。
- 已知构建警告、跨层依赖和端口默认值差异仍见[架构偏差](../architecture/deviations.md)。真实 IAM/Gateway/知识服务联调、Context Path 刷新回退及密钥挂载需要在目标环境验收。

首次成功推送后，如需匿名拉取，维护者应在 GitHub Packages 的 **Package settings → Change visibility → Public** 将包设为公开；若组织策略禁止此操作，联系管理员。若推送被拒绝，也检查已有包的 **Actions access** 是否授予本仓库写权限及组织 Packages 策略。

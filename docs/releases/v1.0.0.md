# v1.0.0 · 谷雨 G2rain 知识库运营应用

谷雨 G2rain 开源 AI Native SaaS 平台的知识库运营前端首个稳定版，与 `g2rain-knowledge v1.0.0` 配套使用。

## 本次发布

- 以“知识内容 → 版本 → 审核 → 处理 → 发布 → 效果验证”组织运营入口。
- 知识内容中的版本管理抽屉，支持文件 / FAQ、审核操作与原文下载等交互。
- 分类、标签与回复模板管理，以及问答 / 检索效果验证页面。
- Vue 3、TypeScript、Vite 与 qiankun；支持独立运行和平台主壳集成。
- 集成模式通过 Auth Bridge 获取 Token；页面和按钮展示配合平台资源，真实接口权限由 Gateway 和后端校验。
- 将生成工具依赖从本机相邻 CLI 目录改为已发布的 `create-g2rain-app@1.0.0`，支持独立仓库安装。

## 配套与使用

- 配套后端：[g2rain-knowledge v1.0.0](https://github.com/g2rain/g2rain-knowledge/releases/tag/v1.0.0)。
- Node.js 22+；按锁文件执行 `npm ci`，再执行 `npm run build`。
- 独立运行仍需要可用的 IAM、Gateway、Basis 资源和知识后端；不是无需平台依赖的离线 Demo。
- [配置说明](https://github.com/g2rain/g2rain-knowledge-app/blob/v1.0.0/docs/operations/configuration.md) · [部署说明](https://github.com/g2rain/g2rain-knowledge-app/blob/v1.0.0/docs/operations/deployment.md)。
- 本次发布源代码快照，不同时发布 npm 应用包、Docker 镜像或含环境配置的静态部署包。

## 验证记录

- 2026-10-19，维护者确认已在服务器端验证通过；具体服务器与平台依赖版本未随记录提供。
- 本地 Vue / TypeScript 检查及 Vite 生产构建通过；独立目录按公开锁文件全新安装依赖并再次构建通过，无需相邻 CLI 仓库。
- 稳定版本是应用软件版本，不代表中央 Frontend App 架构基线已经升级；项目继续记录其试点声明和已知架构偏差。

## 已知限制

- 构建仍提示 MockJS `eval`、大分块、经典 `env-config.js` 与语言模块导入相关警告。
- 当前资源生成工具不生成完整 API endpoint 清单，不能以按钮可见代替接口授权验证。
- 部分跨层依赖与端口默认值差异仍见[架构偏差](https://github.com/g2rain/g2rain-knowledge-app/blob/v1.0.0/docs/architecture/deviations.md)；容器建议显式设置 `SERVER_PORT=8080`。
- 页面提供的操作不代表后端所有可靠性与恢复能力已补齐，请同时阅读后端发布限制。
